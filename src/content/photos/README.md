# Your photos

Put your photos in this folder (`.jpg`, `.jpeg`, `.png` or `.webp`) and they appear in the gallery hall automatically.

- **Order** follows the file names (`01.jpg`, `02.jpg`, … or `IMG_1.jpg`, `IMG_2.jpg`, … both work).
- The **first two** go on the main wall, one on each side of the portal. The rest alternate between the left and right walls.
- Up to 24 photos are shown. Photos around 2000 px on the long side load fastest; huge phone originals work but make the site slower.

**From the GitHub website:** open this folder, click **Add file → Upload files**, drag your photos in and click **Commit changes**. Vercel rebuilds the site by itself in a minute or two.

Privacy: anything in this folder is part of the website. If the repository is public, everyone can see these photos on GitHub, and anyone with the site link can open them. Make the repository private if that matters (Vercel works with private repositories).

Photos saved later through the in-game editor (pencil button, owner code) take the place of this folder's photos.
